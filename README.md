# NewsFusion

A full-stack web application that aggregates the latest news from multiple online sources into a single platform. The application provides categorized news, search functionality, and a responsive user interface for an enhanced reading experience.

## 🛠️ Tech Stack

**Backend:** Python, Flask, REST APIs, BeautifulSoup  
**Frontend:** React.js, HTML, CSS 
**Database:** MongoDB  
**Architecture:** Client-Server Architecture (REST API)  
**Tools:** Git, GitHub, Postman

## ✨ Key Features

- Aggregates news from multiple online sources using web scraping.
- Displays news category-wise (Technology, Business, Sports, Health, etc.).
- Search functionality to quickly find relevant news articles.
- RESTful APIs for seamless frontend-backend communication.
- Responsive and user-friendly interface.
- Dynamic news updates through web scraping.
- Clean and organized presentation of news articles.
